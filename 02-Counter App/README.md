# 🍪 Day 02: Counter Plus

A cute, interactive Counter App built using **HTML, CSS and JavaScript**.

Increase, decrease and reset the counter with interactive buttons, wrapped in a warm, cookie-inspired bakery aesthetic.

## ✨ Features

- Increase the counter value.
- Decrease the counter value.
- Reset the counter to zero.
- Reload button to reset the count.
- Interactive buttons with hover effects.
- Responsive layout for different screen sizes.
- Warm vanilla and chocolate-brown color palette.
- Cookie-inspired UI design.

## 🛠️ Technologies Used

- **HTML5:** Project structure and interactive elements.
- **CSS3:** Styling, layout, hover effects and responsive design.
- **JavaScript:** Counter logic, click events and DOM manipulation.

## 🧠 JavaScript Concepts Learned

| Concept | Purpose |
|---|---|
| `let` | Declaring a variable whose value can change |
| `document.querySelector()` | Selecting HTML elements using CSS selectors |
| `addEventListener()` | Handling button click events |
| `function()` | Defining code to execute when an event occurs |
| `textContent` | Updating the text displayed inside an element |
| Arithmetic Operators | Increasing and decreasing the counter |
| DOM Manipulation | Updating webpage content using JavaScript |
