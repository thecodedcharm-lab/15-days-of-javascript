# 🎨 Day 01: Color Changer

A cute, interactive Color Changer built using **HTML, CSS and JavaScript**.

Click the button to generate a random pastel background color while the grid pattern updates dynamically.

## ✨ Features

- Random background color generation.
- Interactive button.
- Dynamic CSS background updates.
- Pastel color palette.
- Retro-inspired pixel aesthetic.
- Responsive design.

## 🛠️ Technologies Used

- **HTML5:** Project structure.
- **CSS3:** Styling, grid patterns, layout and animations.
- **JavaScript:** Random color generation and DOM manipulation.

## 🧠 JavaScript Concepts Learned

| Concept | Purpose |
|---|---|
| `const` | Declaring variables |
| Arrays | Storing multiple colors |
| `getElementById()` | Selecting an element by ID |
| `addEventListener()` | Handling button clicks |
| `Math.random()` | Generating random numbers |
| `Math.floor()` | Rounding numbers down |
| `querySelector()` | Selecting HTML elements |
| `.style` | Changing CSS using JavaScript |
