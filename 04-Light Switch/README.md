# 💡 Day 04: Light Switch

An interactive Light Switch project built using **HTML, CSS and JavaScript**.

Turn the light ON and OFF with a simple switch. Features a warm lamp illustration, glowing light beam and two different room modes, designed with a minimal cream and charcoal aesthetic.

## ✨ Features

- Interactive ON/OFF light switch.
- Toggle between light and dark room modes.
- Animated background color transition.
- Lamp illustration created entirely with CSS.
- Glowing light beam effect.
- Dynamic messages based on the light status.
- Smooth transitions between both modes.
- Interactive switch with hover and click functionality.
- Responsive layout for different screen sizes.
- Warm cream and charcoal color palette.
- Minimal, lamp-inspired UI design.

## 🛠️ Technologies Used

- **HTML5:** Project structure and interactive elements.
- **CSS3:** Styling, layout, lamp illustration, light beam and transitions.
- **JavaScript:** Switch functionality, event handling and DOM manipulation.

## 🧠 JavaScript Concepts Learned

| Concept | Purpose |
|---|---|
| `const` | Declaring variables that cannot be reassigned |
| `document.getElementById()` | Selecting HTML elements using their IDs |
| `addEventListener()` | Detecting button click events |
| `classList.toggle()` | Switching between CSS classes |
| `classList.contains()` | Checking whether an element has a specific class |
| `textContent` | Dynamically updating text content |
| `if-else` | Executing code based on a condition |
| DOM Manipulation | Dynamically changing webpage appearance and content |
