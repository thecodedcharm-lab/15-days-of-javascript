# 🕒 Day 03: Digital Clock

A stylish, real-time Digital Clock built using **HTML, CSS and JavaScript**.

Displays the current time in hours, minutes and seconds, along with the current day and date. Designed with a soft blue and vanilla aesthetic, featuring animated flip cards.

## ✨ Features

- Displays real-time hours, minutes and seconds.
- Automatically updates every second.
- Supports 12-hour time format (AM/PM).
- Displays the current weekday and date.
- Animated flip effect when digits change.
- Smooth entrance animation.
- Interactive hover effects.
- Responsive layout for different screen sizes.
- Soft blue and vanilla color palette.
- Minimal, clock-inspired UI design.

## 🛠️ Technologies Used

- **HTML5:** Project structure and clock elements.
- **CSS3:** Styling, layout, animations and responsive design.
- **JavaScript:** Time calculations, date formatting and DOM manipulation.
